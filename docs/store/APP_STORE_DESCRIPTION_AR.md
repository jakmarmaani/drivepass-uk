# درايف باس المملكة المتحدة

استعد لاختبار القيادة النظري البريطاني من خلال مراجعة باللغتين الإنجليزية والعربية.

المميزات:
- أسئلة باللغتين الإنجليزية والعربية
- التدريب حسب الموضوع
- اختبارات تجريبية محددة بالوقت
- شرح الإجابات
- حفظ الأسئلة ومراجعة الإجابات الخاطئة
- متابعة التقدم
- دليل لإشارات المرور
- قراءة صوتية باللغتين
- مراجعة دون اتصال بالإنترنت

هذا تطبيق مستقل وغير تابع لوكالة DVSA.
